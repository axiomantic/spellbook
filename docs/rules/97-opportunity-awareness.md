# Opportunity Awareness

!!! info "Optional module"
    The installer offers this module pre-checked. Config key: `rules.module.opportunity-awareness`.

Self-monitoring for reusable artifact candidates and project knowledge gaps at natural pause points.

**Why keep it:** Surfaces skill, command, and agent candidates you would otherwise rebuild by hand.

**If you decline:** The agent will not proactively suggest new spellbook artifacts or flag project knowledge gaps.

**Related artifacts:**

- `skills/opportunity-awareness`
- `skills/writing-skills`
- `skills/writing-commands`

## Rule Content

```markdown
## Opportunity Awareness

After substantive work, consider the `opportunity-awareness` skill for artifact and knowledge gap detection. Surfaces skill/command/agent candidates and AGENTS.md knowledge gaps at natural pause points.

When a candidate becomes a real artifact, load `writing-skills` or `writing-commands` skill for artifact authoring.
```
